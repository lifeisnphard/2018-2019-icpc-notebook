# Problem Solutions

This directory contains complete solutions to specific problems from various online judges and competitions.

## 📚 About

These are full problem solutions from:
- **ICPC** (International Collegiate Programming Contest)
- **IOI** (International Olympiad in Informatics)
- **Codeforces**
- **SPOJ** (Sphere Online Judge)
- **CodeChef**
- **URI Online Judge**
- **AtCoder**
- And other competitive programming platforms

## 🎯 Structure

Each file typically represents a complete solution to a specific problem. File names usually indicate:
1. The problem name (in Portuguese or English)
2. The technique(s) used (sometimes)
3. The online judge code (for SPOJ problems like DQUERY, DSUBSEQ, etc.)

## 💡 How to Use

1. **Learning:** Read solutions to understand different approaches
2. **Reference:** Use as examples when solving similar problems
3. **Practice:** Try to solve the problem first, then compare with the solution
4. **Templates:** Extract reusable code patterns for your own implementations

## ⚠️ Important Notes

- These solutions were written during 2014-2018, primarily in high school
- Code prioritizes competitive programming speed over elegance
- Solutions are tested and accepted by online judges
- Some files contain multiple solution approaches for the same problem
- Comments may be in Portuguese or limited
- Use these as learning resources, not for direct submission
